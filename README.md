# middle-studies-reel

MIDDLE STUDIES REEL の動画置き場（配信専用）。ページ本体は `middle-studies` リポの `reel/`
（https://middle.lab.monakadesign.com/reel/）。

動画をここに分けている理由：middle-studies の GitHub Pages は 2026-09-29 時点で約870MB あり、
Pages の上限 1GB に近い。毎日1本の動画を同じリポに積むと1〜2か月で溢れるため。
このリポも上限は 1GB ＝ `reel/scripts/check.py` が 800MB を超えたら 🔴 を出す。

`NNN_slug.mp4`（1920×1080・60fps・15秒・H.264・8MB以下）を置くだけ。
